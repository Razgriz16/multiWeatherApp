# multiWeatherApp

Aggregates weather data from multiple sources (APIs/scraping), normalizes it,
computes a daily median across sources, and shows it on a simple
self-hosted web page.

## Architecture (locked 2026-09-13)
- **Fetch + normalize**: Python. Pulls from weather APIs (maybe scraping),
  normalizes into a common schema, writes to SQLite.
- **Aggregate**: C. Reads normalized data, computes the daily median
  across sources (v1; accuracy-weighted blending is a possible v2 once
  history exists — see PROJECT-RESEARCH.md §4). Deliberately isolated
  here — portfolio piece, not a performance need.
- **Storage**: SQLite (single file, no DB server).
- **Web serving**: Flask.
- **Frontend**: Flask/Jinja2 server-rendered templates + Pico.css (CDN) for
  styling + Chart.js (CDN) for the trend graph. No node_modules, no build
  step, no bundler. Plain page reload — no HTMX/live-refresh in v1.
